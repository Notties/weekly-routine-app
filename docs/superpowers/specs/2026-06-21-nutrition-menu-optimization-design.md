# โภชนาการต่อเมนู + จัดเมนูเข้าเป้า (Auto จากวัตถุดิบ)

วันที่: 2026-06-21
สถานะ: รออนุมัติ

## เป้าหมาย

ทำให้คลังเมนู/มื้ออาหารในแอป:

1. **มีข้อมูลโภชนาการครบ** — แคลอรี่ + โปรตีน/คาร์บ/ไขมัน (P/C/F) ต่อเมนู
2. **บอกประโยชน์** — บรรทัดสั้น ๆ ว่าเมนูนี้ "ให้อะไร/ช่วยอะไร"
3. **จัดเมนูเข้าเป้าต่อวัน** — ตั้งเป้าแคลอรี่/มาโครตามชนิดวัน แล้วปรับปริมาณ/เมนูให้แต่ละวันเข้าเป้า
4. **ยังประหยัด + มือใหม่ทำได้** — ใช้วัตถุดิบ Makro เดิม, 4 อุปกรณ์เดิม

ขอบเขตที่ **ไม่ทำ** รอบนี้: ของหวาน, แท็บโภชนาการแยก, กราฟซับซ้อน

## หลักการสถาปัตยกรรม (ทาง A — Auto จากวัตถุดิบ)

มาโครเป็น **แหล่งข้อมูลเดียว**: เก็บมาโคร "ต่อ 100 ก." ที่วัตถุดิบ + ระบุ "กรัมต่อเมนู" ในแต่ละ recipe →
มาโครของเมนูและสรุปต่อวัน **คำนวณเอง** สอดคล้องกับที่รายการซื้อของคิดอัตโนมัติอยู่แล้ว และเมื่อสลับเมนู/ปรับปริมาณ ตัวเลขอัปเดตเองทันที

## โมเดลข้อมูล (types.ts)

```ts
/** มาโคร: แคลอรี่ + โปรตีน/คาร์บ/ไขมัน (กรัม) */
export type Macros = { kcal: number; protein: number; carb: number; fat: number };

/** วัตถุดิบในเมนู: ชื่อ (อ้าง catalog) + กรัมที่ใช้จริงต่อ 1 ที่ */
export type RecipeItem = { name: string; grams: number };
```

การเปลี่ยนแปลง type เดิม:

- `CatalogItem` (= `ShopItem`) เพิ่ม `macrosPer100g: Macros`
- `Recipe.ingredients`: `string[]` → `RecipeItem[]`
- `Recipe` เพิ่ม `benefit: string` (ประโยคสั้น "ให้อะไร/ช่วยอะไร")
- `Meal` (resolved) เพิ่ม `macros: Macros` + `benefit: string`
- `Profile` เพิ่ม `weightKg: number`

> หมายเหตุ: มาโครของเมนู **ไม่เก็บ** ในข้อมูล — คำนวณจาก ingredients ทุกครั้ง (single source of truth)

### หน่วยน้ำหนัก (สำคัญ — เขียนไว้ในคอมเมนต์ ingredients.ts)

- **เนื้อสัตว์ (อกไก่/หมู)** = ชั่งน้ำหนัก **ดิบ** (ก่อนทอด)
- **ข้าวสุก** = น้ำหนัก **หลังหุง** (ที่ตักใส่จาน)
- อื่น ๆ = น้ำหนักตามที่กิน · เทียบหน่วยบ้าน: ไข่ 1 ฟอง ≈ 50 ก. · กล้วย 1 ลูก ≈ 100 ก. · แอปเปิล 1 ลูก ≈ 150 ก. · ขนมปัง 1 แผ่น ≈ 30 ก. · นม 1 กล่อง 250 มล. ≈ 250 ก. · เวย์ 1 สกู๊ป ≈ 30 ก. · อัลมอนด์ 1 กำมือ ≈ 28 ก. · เนยถั่ว 1 ช้อนโต๊ะ ≈ 16 ก. · น้ำมัน 1 ช้อน (ดูดซับจริง) ≈ 5 ก.

## เป้าหมายต่อวัน (lib/nutrition.ts)

คำนวณจากโปรไฟล์ (ชาย 75 กก. / 167 ซม. / 25 ปี / เพิ่มกล้าม–ลดไขมัน):

- **BMR** (Mifflin-St Jeor, ชาย) = `10·kg + 6.25·cm − 5·age + 5` = `10·75 + 6.25·167 − 5·25 + 5` ≈ **1,674 kcal**
- คูณกิจกรรมตามชนิดวัน → TDEE → หักดุล ~300–350 เพื่อค่อย ๆ ลดไขมัน
- **โปรตีนคงที่สูง ~2.0 ก./กก. ≈ 150 ก./วัน** (รักษากล้ามระหว่างลดไขมัน)

| ชนิดวัน | ตัวคูณ | TDEE | เป้า kcal | P | C | F |
|---|--:|--:|--:|--:|--:|--:|
| 🏋️ weights (จ/พ/ศ) | 1.50 | ~2,510 | **2,200** | 155 | 260 | 60 |
| 🏃 cardio (อ/พฤ) | 1.45 | ~2,430 | **2,050** | 150 | 235 | 55 |
| 😴 rest (ส/อา) | 1.30 | ~2,175 | **1,850** | 150 | 185 | 55 |

เฉลี่ย ≈ 2,060 kcal/วัน (ขาดดุลเฉลี่ย ~330/วัน ≈ ลดไขมัน ~0.3 กก./สัปดาห์)

ฟังก์ชัน: `dailyTarget(profile, dayType): Macros` (เก็บตัวคูณ/ดุลในไฟล์เดียว แก้ง่าย)

## ตรรกะ (lib/nutrition.ts + lib/nutrition.test.ts)

- `macrosOf(name, grams): Macros` — มาโครของวัตถุดิบ 1 ชนิดตามกรัม (× grams/100)
- `recipeMacros(recipe): Macros` — Σ ของ ingredients
- `sumMacros(list: Macros[]): Macros` — รวมหลายมื้อ
- `dailyTarget(profile, dayType): Macros`
- **TDD**: เขียนเทสต์ก่อน — ตรวจ `recipeMacros` (เมนูตัวอย่างได้ค่าตามคำนวณมือ), `sumMacros`, `dailyTarget` (อินพุตคงที่ → เอาต์พุตที่คาด), ปัดเศษ kcal/กรัมเป็นจำนวนเต็มแบบสม่ำเสมอ

### ตัวอย่างคำนวณ (ln-chicken เวอร์ชันเข้าเป้า)

ข้าวกล้องสุก 220 ก. + อกไก่ดิบ 200 ก. + ผักรวม 120 ก. + น้ำมัน 5 ก.

- ข้าว: 286 / 5.9 / 61.6 / 0.7
- ไก่: 240 / 46 / 0 / 5
- ผัก: 54 / 3 / 9.6 / 0.5
- น้ำมัน: 44 / 0 / 0 / 5
- **รวม ≈ 624 kcal · P 55 · C 71 · F 11**

## รีบาลานซ์สัปดาห์ (recipes.ts + week.ts)

ปรับ **กรัมต่อเมนู** และ/หรือ **เมนูเริ่มต้นใน week.ts** ให้ผลรวมแต่ละวันเข้าเกณฑ์:

- โปรตีนรวม **≥ เป้า** (สำคัญสุด) — เพิ่มอกไก่/ไข่/เวย์ตามต้องการ
- แคลอรี่รวมอยู่ใน **±5%** ของเป้าวันนั้น
- วันพักลดคาร์บ (ข้าวน้อยลง), วันเล่นเวตเพิ่มคาร์บ (ข้าว/กล้วยมากขึ้น)
- คงเมนูมือใหม่ + 4 อุปกรณ์ + วัตถุดิบ Makro เดิม (ไม่เพิ่มของแพง)
- อาจเพิ่มเวย์ในมื้อ/ของว่างบางวันเพื่อดันโปรตีนให้ถึง 150 ก. แบบประหยัด

## UI (คงสไตล์เดิม: rounded-2xl, badge, tnum, muted)

- **`components/nutrition-strip.tsx`** (ใหม่): แถบเล็ก `xxx kcal · P xx · C xx · F xx` (tnum, ตัวเล็ก, muted) — ใช้ซ้ำในการ์ดมื้อ + คลังเมนู
- **`meal-card.tsx`**: เพิ่ม `<NutritionStrip>` + บรรทัด "💡 ช่วยอะไร: …" (benefit)
- **`menu-library-view.tsx` / RecipeCard**: เพิ่ม strip + benefit; แสดงวัตถุดิบพร้อมกรัม (เช่น "อกไก่ 200 ก. · ข้าวกล้อง 220 ก.")
- **`components/daily-nutrition-summary.tsx`** (ใหม่) บนสุด `meal-view.tsx`: รวมวันนี้ **vs เป้า** + แถบ progress 2 ตัว (kcal, โปรตีน) + C/F เป็นตัวเลข; สีเตือนเมื่อโปรตีนยังไม่ถึง/แคลอรี่เกิน
